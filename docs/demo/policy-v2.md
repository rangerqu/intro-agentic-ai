# 会议材料报送说明（虚构演示材料）

版本：V2  
发布日期：2026-09-01  
生效日期：2026-09-15

## 第 1 条：适用范围

本说明适用于每周四召开的部门例会。项目专题会另行安排。

## 第 2 条：常规报送时间

参会人员应在周二 17:00 前，将材料提交至指定资料目录。

## 第 3 条：临时议题

临时议题可经会议负责人确认后补充提交。

## 第 4 条：材料命名

文件名应包含会议日期、议题名称和版本号。

## 附件：材料清单

1. 议题摘要。
2. 相关事实及来源。
3. 需要讨论的问题。
4. 上次行动项进展。
